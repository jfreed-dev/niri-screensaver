# Code of Conduct

This project adopts the
[Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is canonical; the short version:

- Be respectful in issues, PRs, and discussions.
- Assume good faith. Disagree on the technical merits, not the person.
- No demographic put-downs, no doxxing, no spam.

If you see a violation or experience one, email the maintainer
(see the GitHub profile of the repo owner). Reports will be handled
in confidence.
